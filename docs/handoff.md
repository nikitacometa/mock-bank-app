## 3. Что делать дальше (в порядке)

**KBT-004 — визуальная верификация всего, что не Home.** History, Cards (карусель + tilt),
все четыре шита, success-сцена перевода, тост, ErrorBoundary-фолбэк (сломать компонент
нарочно). Метод: `pnpm dev --port 5199` + `npx playwright screenshot` на [390/460/700/900]
(Chrome-расширение в прошлой сессии не подключалось — не рассчитывай на него, проверь).
Интерактивные флоу скриншотом не проверяются — нужен кликабельный прогон (playwright script
или руками у владельца). Чек-лист «не generic AI» — spec §5.4 анти-цели.

**KBT-005 — AC майлстоунов M2-M5 по спеке §6.** Особенно: двойной быстрый тап «Перевести»
(explicit probe), недостаток средств до сабмита, freeze через reload, два таба браузера
синхронны, count-up только на изменение.

**KBT-006 — полировка M6.** Известные ниты со смоука Home:
- разделитель тысяч в моно-балансе даёт слишком широкую щель («28 456») — сузить
  (например, `letter-spacing` на разделителе или замена на U+2009);
- сид генерирует время в UTC-часах, локальный рендер даёт «Покупки · 3:26» ночью —
  генерировать в локальном сдвиге демо-аудитории (МСК) или сместить окна в `seed.ts:at()`;
- a11y-гейт: приглушённая тёмная палитра почти наверняка провалит AA на `--color-ink-3`
  с первой попытки (red team №4) — заложи несколько раундов подбора оттенков;
- копирайт-проход по всем строкам UI (без канцелярита) и ревью правдоподобия сида глазами.

**Дальше** — KBT-007 деплой (`*.pages.dev`), KBT-009 GitHub (nikitacometa, private —
бренд-риск имени репо описан в spec §7), KBT-010 TMA-порт (probe до старта обязателен).
